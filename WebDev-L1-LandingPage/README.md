# SONORA — Music Discovery Landing Page

A responsive landing page for a fictional music discovery brand. This is the Level 1 Landing Page project for the Oasis Infobyte Web Development & Designing internship.

## Features
- Sticky navigation with CSS-only responsive links
- Hero section with call-to-action buttons
- Six mood-based playlist cards
- Discovery/features section
- Closing call to action and footer
- Responsive layout using CSS Grid and Flexbox

SONORA is a fictional concept. The playlist cards are visual examples and do not play music or connect to a streaming service.
